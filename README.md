## О проекте

**KawaiiTasks** — консольное приложение для организации разработки программного продукта. Оно помогает вести несколько IT-проектов, распределять задачи между участниками команды, контролировать сроки и учитывать фактически затраченное время.

Интерфейс построен на `Spectre.Console`: вместо стандартного набора команд используются цветные панели, таблицы, карточки задач и интерактивные меню. Визуальная тема сочетает лавандовые, розовые и мятные акценты.

Проект разработан в рамках курсовой работы по теме **«Система управления задачами IT-проекта»**.

## Интерфейс

В приложении предусмотрены несколько способов просмотра задач: канбан-доска по статусам, общая таблица и подробная карточка выбранной задачи. На главном экране проекта отображаются прогресс, распределение задач по статусам, затраченное время и сведения о просроченных задачах.

> GIF-анимации в шапке и разделах README — декоративные элементы страницы. Они не являются записью экрана приложения.

## Технологии

| Технология | Назначение |
|---|---|
| **C# 12** | Основной язык разработки |
| **.NET 8** | Платформа выполнения и сборки приложения |
| **Spectre.Console 0.49.1** | Цветной консольный интерфейс, таблицы, панели и интерактивный вывод |
| **System.Text.Json** | Сериализация и сохранение данных в JSON |
| **xUnit** | Модульное тестирование |

В проекте используются объектные модели, отдельный сервисный слой, интерфейсы для хранения данных и формирования отчётов. Это позволяет разделять пользовательский интерфейс, бизнес-логику и инфраструктурные компоненты.

## Установка и запуск

### Требования

- Windows, Linux или macOS
- Установленный [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
- Git — для клонирования репозитория

Проверить установку .NET можно командой:

```bash
dotnet --version
```

### Запуск из исходного кода

```bash
git clone https://github.com/kutsyfugaputik/kawaiitask.git
cd kawaiitask

dotnet restore
dotnet run --project KawaiiTasks.csproj
```

Для Windows также предусмотрен файл `Run.bat`. Его можно запустить двойным щелчком мыши или из командной строки:

```bat
Run.bat
```

### Сборка проекта

```bash
dotnet build KawaiiTasks.csproj
```

## Хранение данных

Данные сохраняются автоматически в JSON-файл и загружаются при следующем запуске приложения. Файл находится в системной папке пользовательских данных:

| Операционная система | Расположение |
|---|---|
| Windows | `%LOCALAPPDATA%\KawaiiTasks\data.json` |
| Linux | `~/.local/share/KawaiiTasks/data.json` |
| macOS | `~/Library/Application Support/KawaiiTasks/data.json` |

Таким образом, данные пользователя не зависят от папки, в которую склонирован репозиторий.

## Тестирование

Для запуска модульных тестов из корневой папки проекта выполните:

```bash
dotnet test Tests/KawaiiTasks.Tests.csproj
```

Тестовый проект использует **xUnit**. Проверяются модели проектов и задач, сервисная логика, фильтрация и сортировка, JSON-хранилище, формирование отчётов и вспомогательные компоненты интерфейса.

## Основные принципы реализации

- **Разделение ответственности:** модели описывают сущности предметной области, сервисы реализуют операции, UI отвечает за взаимодействие с пользователем.
- **Инкапсуляция:** изменение состояния проектов и задач выполняется через предусмотренные методы моделей и сервисов.
- **Обработка ошибок:** предусмотрена проверка пользовательского ввода и обработка исключительных ситуаций.
- **Сохранение состояния:** изменения записываются в JSON, поэтому данные остаются доступными между запусками.
- **Тестируемость:** ключевые компоненты отделены от консольного интерфейса и покрыты модульными тестами.
